# T12 — 模板与受控实例创建技术设计

版本：0.1；状态：G2 前置设计。

---

## 1. 业务目标与安全边界

为支持多实例批量部署，需从经过基线加固与预装测试工具的“黄金模板”快速克隆新实例。

### 安全红线
1. **脱敏保护**：黄金模板镜像内严禁包含任何真实业务账号密码、Token、私有密钥或个人隐私文件；
2. **基底保护**：被克隆实例引用的基底模板版本不可变，只要引用计数 `RefCount > 0`，平台底层严格拒绝删除；
3. **破坏操作二次确认**：对实例的重置、删除、恢复旧快照等不可逆操作，UI 必须显式展示数据损失影响并强制二次确认；
4. **磁盘准入保护**：创建或克隆前，检测目标磁盘剩余空间，低于阈值（如 `max(10%总空间, 10GB)`）时拒绝执行并提示操作者。

## 2. 模板生命周期状态机

```text
Draft (草稿制作) 
   │
   ▼
Active (已冻结/可克隆) ──[克隆生成实例，RefCount++]──> 实例运行
   │
   ├─[存在引用，拒绝删除]
   │
   ▼ (当 RefCount == 0 时)
Archived / Deleted (已归档/销毁)
```

---

## 3. 克隆机制与降级策略

1. **差分克隆 (Linked Clone)**：
   - 依赖虚拟化底层对快照或只读 base disk 的支持；
   - 优点：磁盘占用低（MB 级别）、创建速度极快（秒级）；
   - 风险：基底损坏将导致所有派生实例损坏。
2. **完整克隆 (Full Clone，首期稳定选型)**：
   - 完整复制磁盘镜像文件，彻底实现文件系统与状态物理隔离；
   - 优点：实例间无任何文件链依赖，一个实例损坏或重置绝不波及其他实例；
   - 成本：耗费磁盘空间（每个实例 2~4GB），创建耗时约 10~30 秒。
   - **降级决策**：在厂商底层差分接口未完成充分可靠性实测前，首期默认采用安全隔离的完整克隆，并在 UI 明确显示预计耗时。
